What is Python?

Python is a high-level, interpreted programming language known for its simple and readable syntax. It is widely used in web development, data science, automation, artificial intelligence, and more.

print("Hello, World!")

Variables and Data Types

Variables in Python do not need explicit declaration to reserve memory space.

name = "Alice"      # String

age = 25            # Integer

height = 5.5        # Float

is_student = True   # Boolean

Common data types:

  • str (String)
  • int (Integer)
  • float (Floating point)
  • bool (Boolean)
  • list, dict, tuple, set (Collections)

Conditional Statements

Python uses if, elif, and else for decision-making.

age = 18

if age >= 18:

  print("You are an adult.")

else:

  print("You are a minor.")

Indentation is crucial in Python and replaces curly braces used in other languages

Loops

Python has for and while loops for repeating tasks.

# For loop
for i in range(5):
  print(i)

# While loop
count = 0
while count < 5:
  print(count)
  count += 1

Functions

Functions allow you to group code into reusable blocks.

def greet(name):
  return f"Hello, {name}!"

print(greet("Alice"))

Functions are defined using the def keyword, followed by the function name and parentheses.
